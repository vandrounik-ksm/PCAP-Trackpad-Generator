# 🖱️ PCAP Trackpad Generator

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![OpenSCAD](https://img.shields.io/badge/OpenSCAD-Generator-blue.svg)](https://openscad.org/)

Простой и гибкий параметрический генератор емкостных трекпадов (touchpad/trackpad), написанный на **OpenSCAD**. 

Инструмент создает 2D-шаблон (ромбовидную матрицу сенсоров), который можно легко экспортировать в формат **DXF** и импортировать в любую программу для проектирования печатных плат (KiCad, Eagle, Altium Designer и др.).

---

## ✨ Возможности

- 📐 **Параметрический дизайн**: Полная настройка размеров, количества строк/столбцов и зазоров.
- 🔷 **Выбор формы**: Поддержка круглой, квадратной и прямоугольной формы со скругленными углами.
- 🛡️ **Земляная рамка (Ground Frame)**: Возможность добавления защитной земляной рамки с настраиваемой шириной и отступом.
- 📤 **Готовность к производству**: Чистый экспорт в DXF для прямого импорта в PCB-редакторы.

## 🛠️ Требования

- Установленный [OpenSCAD](https://openscad.org/downloads.html)

## 🚀 Использование

1. **Скачайте** файл `Trackpad-generator.scad` из этого репозитория.
2. **Откройте** его в программе OpenSCAD.
3. **Настройте параметры** в левой панели (раздел "Параметры" / "Customizer"), изменив значения под ваши задачи (см. таблицу ниже).
4. Нажмите **F5** (Preview) для предпросмотра результата.
5. Нажмите **F6** (Render) для финального рендеринга модели.
6. **Экспортируйте** результат: `File` → `Export` → `Export as DXF`.

---

## ⚙️ Описание параметров

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `shape` | `2` | Форма трекпада: `0` = Круг, `1` = Квадрат, `2` = Прямоугольник со скруглениями |
| `rows` | `6` | Количество строк сенсоров |
| `columns` | `6` | Количество столбцов сенсоров |
| `touchpad_width` | `26` | Общая ширина платы (мм) |
| `touchpad_height` | `26` | Общая высота платы (мм) |
| `diamond_spacing` | `0.2` | Минимальный зазор между вершинами соседних ромбов (мм) |
| `corner_radius` | `5.0` | Радиус скругления углов (актуально при `shape = 2`) |
| `enable_ground_frame` | `1` | Включение земляной рамки (`1` = да, `0` = нет) |
| `ground_frame_width` | `1.0` | Толщина земляной рамки (мм) |
| `ground_frame_offset` | `0.5` | Зазор между рамкой и сеткой сенсоров (мм) |

> 💡 **Совет:** Убедитесь, что значение `ground_frame_width` меньше `corner_radius`, если выбрана форма со скруглениями. В противном случае OpenSCAD может вывести предупреждение о возможных геометрических артефактах.

## 📦 Интеграция с PCB-редактором

После экспорта в DXF:
1. Импортируйте DXF-файл в ваш PCB-редактор (например, в KiCad через *File → Import → Graphics*).
2. Поместите контур на нужный слой (например, *F.Cu* или *User.Drawings*).
3. Используйте контуры ромбов как основу для создания полигонов емкостных сенсоров.
4. Настройте правила проектирования (Design Rules), чтобы гарантировать соблюдение зазоров, указанных в параметре `diamond_spacing`.
